# 目录规范整改计划

依据根目录《目录规范.md》，采用根 Go 后端 + web React SPA 布局。

1. 将 HTTP 装配并入 internal/app；测试辅助代码移到测试文件。
2. 前端共享 UI、布局、API、样式和浏览器测试按规范迁移，同步全部导入与测试发现。
3. CONFIG_FILE 选择 configs/config.local.yaml；环境覆盖优先于文件和默认值，无旧入口回退；图标缓存迁到 .cache，保留本地内容。
4. 同步 CI/CD 直接调用的 Go/npm 命令、Docker、忽略规则和双语文档，不保留别名。
5. 运行静态检查、单元与浏览器测试，在不含配置/依赖/产物的副本中安装、检查、构建和最小启动；记录实际结果。
