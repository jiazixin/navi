# UI 规范

本文件保留长期有效的界面约定。具体数值以 `web/src/styles/tokens.css` 与组件 CSS 为准；验收命令见 [IMPLEMENTATION.md](IMPLEMENTATION.md)。

## 设计语言

主题为「等高 / Contour」：导航页是一张私人地图，视觉取自地图与雕版——等高线、指南针标志、等宽数字和坐标式小字。显示字体统一为打包的 JetBrains Mono（时钟、编号、品牌、标签），中文标题使用系统宋体，正文使用系统无衬线字体；不从外部 CDN 加载字体。

色调（`data-theme`）四种：墨夜 ink（香槟金）、宣纸 paper（朱砂）、青瓷 celadon、暮紫 dusk；default 跟随系统深浅色解析为 ink 或 paper。正文、次要与弱化文字在背景、面板与卡片上均满足 WCAG AA（≥4.5:1）。强调色集中在编号、焦点、选中与少量线条。

动态纹样五种，以 Canvas 绘制并跟随当前色调：等高线 contour、流场 flow、扭索纹 guilloche、星轨 stars、山峦 ridge，另有素净 none。纹样对鼠标有响应，固定在内容之下，不拦截输入，不遮挡文字、焦点或浮层；首屏文字下有柔和遮罩保证可读，滚动后纹样减弱。

## 页面结构

账号密码均为空时直接显示首页，隐藏退出入口，加载认证模式时不展示登录表单。启用认证且未登录时显示 `/login`：桌面为品牌宣言与登录卡双栏、窄屏收为单栏，背景沿用配置的色调与纹样。账号和密码均有可见标签及自动填充语义，支持密码显隐、Enter 提交、提交中禁用按钮、错误提示和连接失败重试。登录前不挂载目录与 SSE。

登录后自上而下：固定顶栏（品牌、多页标签、搜索、刷新与连接状态、外观、退出）、状态提示、首屏（日期行、大号时钟、问候语、搜索框与搜索入口）、首屏底部的目录提示与当前纹样、分区目录与分组卡片、页脚。分区目录桌面为粘性侧栏并随滚动高亮当前分组，≤1080px 变为顶栏下可横向滚动的分区标签。卡片以 CSS Grid 自动分列，手机为单列。

卡片显示站点图标（后台图标到达前显示按名称着色的字标）、名称、描述（缺失时显示域名）、域名和「内网」标记；悬停时上浮，指针附近的卡片边框共同发光。跳转统一经 `/go/{runtimeId}` 在新标签打开。

## 交互

- 首屏搜索同时筛选所有页面的链接（名称、标签、域名、描述、分组）并在末尾提供外部搜索；方向键、Home/End 选择，Enter 打开，Escape 先清空再失焦，外部点击收起。输入法组合期间不响应快捷键。
- `⌘K` / `Ctrl+K` 打开快速搜索弹层，`/` 在首屏聚焦搜索框、滚动后打开弹层；输入框内的 `/` 不被截获。弹层为模态，Tab 保持在输入框，Escape 或点击遮罩关闭并把焦点还给触发按钮。
- 外部搜索空查询不打开页面。Claude/Gemini 打开站点并尝试复制查询，复制失败也有反馈。
- 外观面板为非模态浮层：纹样与色调为单选组，方向键与 Home/End 移动并选择；含纹样强度与动态效果开关；Escape 关闭并恢复焦点，外部点击关闭。
- 多页标签切换内容并记住所选页；切页时如已滚过首屏则回到目录顶部。
- 合法热更新保留当前内容；加载、失败（可重试）、降级、断线、空目录、无匹配结果都有清晰状态。跳转失败页沿用色调与纹样，提供至少 44px 的重试与返回入口。

## 动效与可访问性

纹样由单一 `requestAnimationFrame` 循环驱动，标签页隐藏时暂停；遵循 `prefers-reduced-motion` 或用户关闭动态效果时只绘制一帧静态画面，并简化卡片入场与悬停位移。卡片入场动画结束后必须完全不透明。共享关键帧通过 CSS 变量引用，避免被 CSS Modules 重命名。

交互目标至少 44×44px，图标命令有可访问名称，键盘无陷阱。目标为 WCAG AA 对比度、无 serious/critical axe 问题。不得通过隐藏页面横向溢出来掩盖布局错误，装饰性遮罩须留在视口内。需要分别验证实际浏览器缩放、字体放大和真机触控；仅调整 viewport 不等于完成这些验证。

## 检查矩阵

代表视口：320×568、390×844、768×1024、1024×768、1280×800、1440×900 和超宽屏。浏览器覆盖 Chromium、Firefox、WebKit。

检查空目录、长文本、多分组、多分页、1000 链接、加载、失败与重试、降级、断线恢复、图标到达、全部色调与纹样（动态与静态）。检查无横向滚动、意外遮挡、焦点裁切。

视觉基线位于 `web/e2e/visual.spec.ts-snapshots`，测试固定时间、使用静态纹样帧；更新基线前人工检查差异，不能为消除失败直接接受新截图。真实手机、200%/400% 缩放、高 DPI 和高刷新率体验属于发布前人工检查。

## 实现断点

宽度断点统一登记为 420、720、900、1080、1200 CSS px，分别用于窄屏顶栏、手机布局、登录双栏、目录索引与宽屏留白。交互能力查询另使用 hover、forced-colors 与 prefers-reduced-motion。
