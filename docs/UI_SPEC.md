# UI 规范

本文件保留长期有效的界面约定。具体数值以 `web/src/styles/tokens.css`、组件 CSS 和 `web/src/styles/motion.ts` 为准；验收命令见 [IMPLEMENTATION.md](IMPLEMENTATION.md)。

## 页面与视觉

账号密码均为空时直接显示首页，隐藏退出入口，加载认证模式时不展示登录表单。启用认证且未登录时显示 `/login`：桌面为品牌轨道图形与登录表单双栏，手机收为单栏；复用主题颜色、焦点与字体。账号和密码均有可见标签及自动填充语义，支持密码显隐、Enter 提交、提交中禁用按钮、错误提示和连接失败重试。登录前不挂载目录与 SSE；成功进入首页。顶栏“退出登录”撤销会话后返回登录页。登录页不展示导航内容。

登录后页面顺序：顶栏、状态提示、外部搜索工作台、当前页分组与链接卡片、分页。导航筛选只搜索当前页的名称、分组、描述和标签，保留分组上下文；切页清空筛选。外部搜索与“搜索导航”须有不同可访问名称。

默认主题跟随系统深浅色；彩色主题以安静、低彩度画布为主。边框保持中性，主题色集中在选中、焦点、图标和小面积反馈。普通卡片圆角 8px，图标框 36×36px，交互目标至少 44×44px。不得通过隐藏页面横向溢出来掩盖布局错误。

共享间距遵循 4px 网格；正文和名称保留完整 accessible name。长文本可省略或换行，放大字体时不得覆盖图标、控件或相邻卡片。卡片以内容驱动的 CSS Grid 自动分列，窄屏回流到单列。

浮层菜单使用不透明 surface、统一边界和阴影，不能透出底层搜索文字和纹样。常驻搜索椭圆允许受控 blur；不支持 blur 时内容仍清晰可读。

## 交互

- `/`、Ctrl/Cmd+K 聚焦导航筛选；输入框中 `/` 不被截获。Escape 清空或关闭，Tab 顺序自然；Escape 或关闭按钮关闭弹层时恢复触发器焦点。
- 手机使用搜索弹层，桌面使用常驻筛选框；弹层关闭按钮始终可达，横竖屏切换不丢失必要状态。
- 主题、背景、provider 菜单支持方向键、Home/End、Enter、Escape、Tab 与外部点击关闭；Tab 关闭菜单后允许焦点继续移出，不强制跳回触发器。图标命令有可访问名称。
- 外部搜索支持按钮及 Enter；空查询不打开页面。Claude/Gemini 尝试复制查询并打开入口，复制失败也有反馈。
- 桌面外部搜索椭圆指针进入后展开，保持约 8 秒；focus/menu-open 时不收回。手机满宽，不执行桌面宽度计时动画。
- 卡片新标签跳转。失败页沿用主题、字重与共享错误组件样式，提供至少 44px 的重试和返回入口，窄屏无溢出。图标加载失败显示字标，后台图标更新后重试，固定图标框避免布局跳动。
- 合法热更新保留当前可用内容；API 失败、降级、断线、空目录、无结果都有清晰状态和恢复路径。

## 动效与可访问性

使用共享 duration/easing/spring token；交互不能等动画结束才可用。遵循 prefers-reduced-motion，停止背景环境动画并简化位移。动画跟随浏览器刷新节奏，不用固定 FPS timer 驱动。

普通动效和 reduced motion 都必须实际显示目录内容；入场透明度不能在动画装配中停留为零。手机搜索结果中的卡片焦点仍可用 Escape 关闭弹层，输入法组合期间不误触关闭。

彩色 provider 图标保留品牌色，不被主题文字色覆盖；主题切换不更换不必要的 DOM 实例。纹样属于背景，不拦截输入，不遮挡文字、焦点或菜单。

目标为 WCAG AA 对比度、无 serious/critical axe 问题，键盘无陷阱。需要分别验证实际浏览器缩放、字体放大和真机触控；仅调整 viewport 不等于完成这些验证。

## 检查矩阵

代表视口：320×568、390×844、768×1024、1024×768、1440×900、1920×1080 和超宽屏。浏览器覆盖 Chromium、Firefox、WebKit。

检查空目录、长文本/emoji、无空格长词、多分组、多分页、500/1000 链接、加载、失败、断线恢复、图标到达、所有主题与纹样菜单。普通动效和 reduced motion 分别检查实际可见性、交互与焦点。检查无横向滚动、意外遮挡、同排卡片错位或焦点裁切。

视觉基线位于 `web/e2e/visual.spec.ts-snapshots`；更新基线前人工检查差异，不能为消除失败直接接受新截图。真实手机、200%/400% 缩放、高 DPI 和 165Hz 体验属于发布前人工检查，不用历史通过记录代替本次结果。
